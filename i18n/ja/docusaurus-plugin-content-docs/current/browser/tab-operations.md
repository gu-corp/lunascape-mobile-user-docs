# タブ操作

デフォルトの最大タブ数は12です。ユーザーは設定（設定 → タブ → 最大タブ数を設定）で最大タブ数を変更できます。ブラウジングパフォーマンスに影響を与えないよう、最大数は大きすぎないことをお勧めします。

デフォルトのタブモードはスライディングタブバーです。ユーザーは設定 → タブでモードとその他の設定を変更できます。

Webページで下にスクロールすると、タブバーは自動的に非表示になります（アドレスバーも同様）。ユーザーは設定 → ツールバーとタブバーでこの設定を変更できます。

体験を向上させるため、柔軟なタブを使用して、Lunascapeはタブで一連のクイックアクションを提供します。

- タブを約2秒間タッチしてホールドすると、クイックアクションメニューが表示されます。サポートされているアクション：閉じる、他のタブを閉じる、お気に入りに追加（ブックマーク）、このタブを再読み込み。

![Screenshot 2025-09-09 at 17.43.14.png](img/Screenshot_2025-09-09_at_17.43.14.png)

- ホームアイコンをタッチ、ホールドして上/左/右にスワイプすると、ジェスチャークイックアクションが表示されます。サポートされているジェスチャークイックアクション：閉じる、戻る、前へ。
