# 検索

提供された検索エンジンを使用したクイック検索。
Lunascapeは以下の検索エンジンを提供します：

- Google
- Bing
- Amazon
- Youtube
- Twitter/X
- Wiki
- DeepL
- ebay

ユーザーの検索履歴のリストも表示され、検索がより高速になります。
