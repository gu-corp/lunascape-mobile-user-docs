# 広告ブロック

広告ブロックはデフォルトで無効になっています。広告をブロックしたい場合は、手動で有効にする必要があります。
広告ブロックが有効になると、機能が実際に動作するためにWebページを再読み込みする必要があります。

![Simulator Screenshot - iPhone 15 - 2025-09-09 at 15.35.14.png](img/Simulator_Screenshot_-_iPhone_15_-_2025-09-09_at_15.35.14.png)

広告ブロック用のAllowList機能（設定 → 広告ブロッカー → 許可リスト）も提供しています。このリストに追加されたサイトでは広告ブロックは機能しません。
