# ファイルダウンロード

ブラウザは、ほとんどのオーディオ、ビデオ、画像、文書、その他のファイル形式のダウンロードをサポートしています。

iOSの場合、ダウンロードされたすべてのファイルは*On My iPhone/Lunascape/Downloads*に保存されます。これらはFilesアプリでも表示されます。ユーザーはLunascapeとFilesアプリを通じてダウンロードされたファイルを編集/削除できます。Lunascapeアプリがアンインストールされると、Lunascapeによってダウンロードされたすべてのファイル**は削除されます**。

Androidの場合、ダウンロードされたファイルは*Downloads/Lunascape*に保存されます。これらは他のファイルマネージャーアプリでも表示されます。ユーザーはLunascapeと他のファイルマネージャーアプリの両方でファイルを編集/削除できます。Lunascapeアプリがアンインストールされても、Lunascapeによってダウンロードされたファイル**は削除されません**。

Lunascapeは以下のアクションをサポートします：ファイルのダウンロードを一時停止/再開/キャンセル、ダウンロードされたファイルを編集/削除。
