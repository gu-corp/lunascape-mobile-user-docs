# 概要

Lunascapeは高速で安全なモバイルブラウザを提供します。内蔵の広告ブロックとWeb3 DAppサポートで体験を向上させます。

## 目次

- [広告ブロック](ad-blocking) - 広告をブロックし、許可リスト設定を管理
- [検索](search) - 複数の検索エンジンを使用し、検索履歴を表示
- [ブックマーク](bookmarks) - お気に入りのWebサイトを保存・整理
- [リーディングリスト](reading-list) - 読み取り/未読ステータスでページを追跡
- [ブラウジング履歴](browsing-history) - ブラウジング履歴を表示・検索
- [タブ操作](tab-operations) - 複数のタブとプライベートブラウジングを管理
- [ファイルダウンロード](download-file) - Webからファイルをダウンロード・管理
- [共有](share) - 他のアプリとWebページを共有
- [Web3 DAppサポート](web3-dapp-support) - ウォレットを使用してWeb3 DAppに接続
- [プライベートモード](private-mode) - データを保存せずにプライベートブラウジング（iOSのみ）
- [ブラウザツールメニュー](browser-tool-menu) - ブラウザツールと設定にアクセス

## このセクションでカバーする内容

このセクションでは、Lunascapeで利用可能なすべてのブラウザ機能と機能を説明します。以下の方法を学びます：

- 広告をブロックし、広告ブロック設定をカスタマイズ
- 複数の検索エンジンを使用した効率的な検索
- ブックマークの整理とリーディングリストの作成
- ブラウジング履歴とタブの管理
- ファイルのダウンロードとコンテンツの共有
- 分散アプリケーションのためのWeb3機能の使用
- プライベートブラウジングとブラウザツールへのアクセス

Lunascapeブラウザは、モバイルブラウジング体験を向上させる多くの機能とユーティリティを提供します。
