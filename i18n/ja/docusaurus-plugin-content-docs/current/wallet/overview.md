# ウォレット概要

LunascapeはユーザーにEVMウォレットを提供します。Ethereum、Binance Smart Chain、Polygon、Avalanche C-Chain、Fantom、Arbitrum、OptimismなどのほとんどのEVMブロックチェーンをサポートしています。

ウォレットはBitcoin、Solana、Ripple、Cardano、Nearなどの非EVMブロックチェーンをサポートしていません。

ユーザーはEVMで動作するDApps DeFi、GameFi、NFTマーケットプレイスとやり取りできます。

## このセクションでカバーする内容

このセクションでは、Lunascapeの内蔵Web3ウォレット機能の使用方法を説明します。以下の方法を学びます：

- シードフレーズを使用してウォレットを作成またはインポート
- ウォレットダッシュボードを使用して残高と取引を表示
- 暗号通貨資産とトークンを管理
- ウォレット設定とセキュリティオプションを構成
- 分散アプリケーション（DApps）に接続
- WalletConnectを使用して外部ウォレットに接続
- 様々なウォレット操作と取引を実行

内蔵ウォレット機能により、別のウォレットアプリケーションを必要とせずに、ブラウザから直接Web3サービスにアクセスできます。
