<div>
<div>
次の手順で、前回のタブを復元することができます。

※前回のタブを復元とは：

Lunascapeモバイル終了後、再起動した際に前回開いていたタブを表示させる機能です。

1. ページ下部の三点リーダーをタップします。

<img class="hs-image-align-none" height="699" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-23%2014-38-10-png.png" width="350" loading="lazy" />

2. 「設定」をタップします。

<img class="hs-image-align-none" height="701" src="https://www.gu-tech.com/hubfs/%E8%A8%AD%E5%AE%9A%E3%82%92%E3%82%BF%E3%83%83%E3%83%97-png-3.png" width="350" loading="lazy" />

3. 「タブ」をタップします。

<img class="hs-image-align-none" height="649" src="https://www.gu-tech.com/hubfs/%E3%82%BF%E3%83%96%E9%81%B8%E6%8A%9E-png-1.png" width="350" loading="lazy" />

4. 「タブを復元」をオンにします。

<img class="hs-image-align-none" height="717" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-23%2014-39-30-png.png" width="350" loading="lazy" />
