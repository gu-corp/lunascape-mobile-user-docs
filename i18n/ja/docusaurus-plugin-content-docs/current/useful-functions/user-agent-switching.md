title: User Agentの切り替え
---


次の手順で、User Agentの切り替えを行うことができます。

1. ページ下部にある三点リーダーをタップします。

<img class="hs-image-align-none" height="703" src="https://www.gu-tech.com/hubfs/%E3%83%9B%E3%83%BC%E3%83%A0%EF%BC%9E%E8%A8%AD%E5%AE%9A-png-Jan-23-2024-06-20-43-1555-PM.png" width="350" loading="lazy" />

2. 「設定」をタップします。

<img class="hs-image-align-none" height="701" src="https://www.gu-tech.com/hubfs/%E8%A8%AD%E5%AE%9A%E3%82%92%E3%82%BF%E3%83%83%E3%83%97-png-Jan-23-2024-06-20-55-6239-PM.png" width="350" loading="lazy" />

3. 「User Agent」をタップします。

<img class="hs-image-align-none" height="713" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-24%203-21-24-png.png" width="350" loading="lazy" />

4. 任意のUser Agentをタップし、チェックマークをつけます。

<img class="hs-image-align-none" height="637" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-24%203-22-21-png.png" width="350" loading="lazy" />
