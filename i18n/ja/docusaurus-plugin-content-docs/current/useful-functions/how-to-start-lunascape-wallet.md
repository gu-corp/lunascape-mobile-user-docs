title: Lunascape Walletの始め方
---


Lunascapeではweb3ウォレットであるLunascape Walletを使って、クリプトの管理を行うことができます。Lunascape Walletの使用開始方法は以下の手順となります。

1. 右下の「3点リーダーアイコン」をタップします。

<img class="hs-image-align-none" height="703" src="https://www.gu-tech.com/hubfs/%E3%83%9B%E3%83%BC%E3%83%A0%EF%BC%9E%E8%A8%AD%E5%AE%9A-png-Jan-23-2024-09-13-31-2184-PM.png" width="350" loading="lazy" />

2. ウォレットボタンをタップします。
<img alt="ウォレットボタン" class="hs-image-align-none" height="757" src="https://www.gu-tech.com/hubfs/img-lunascapewallet9.png" width="350" loading="lazy" />

3.「新しいウォレットを作成」ボタンをタップしてください。
<img alt="新しいウォレットを作成" class="hs-image-align-none" height="847" src="https://www.gu-tech.com/hubfs/img-lunascapewallet.png" width="350" loading="lazy" />

4. パスワードを作成し、「次へ」ボタンをタップしてください。

「Face IDでロック解除」をONにすると次回からのログインが簡単になります。
<img alt="パスワードを作成" class="hs-image-align-none" height="757" src="https://www.gu-tech.com/hubfs/img-lunascapewallet2.png" width="350" loading="lazy" />

5. 利用規約に同意する場合は、それぞれの項目を選択した後、新規作成ボタンをタップします。

<img alt="利用規約" class="hs-image-align-none" height="757" src="https://www.gu-tech.com/hubfs/img-lunascapewallet3.png" width="350" loading="lazy" />

6. シードフレーズを確認、コピーすることができます。ウォレットやクリプトのマスターキーとして、シードフレーズを安全な場所へ保管してください。このシードフレーズを失うと、仮想通貨や資産にアクセスできなくなり、暗号資産を失います。
<img alt="シードフレーズについて" class="hs-image-align-none" height="865" src="https://www.gu-tech.com/hubfs/img-lunascapewallet6.png" width="400" loading="lazy" />
<img alt="シードフレーズのバックアップ" class="hs-image-align-none" height="865" src="https://www.gu-tech.com/hubfs/img-lunascapewallet7.png" width="400" loading="lazy" />
<img alt="シードフレーズのコピー" class="hs-image-align-none" height="865" src="https://www.gu-tech.com/hubfs/img-lunascapewallet8.png" width="400" loading="lazy" />

7.シードフレーズの保管が完了したあと、戻るボタンでLunascape Walletのマイページにアクセスすることができます。
<img alt="マイページ" class="hs-image-align-none" height="865" src="https://www.gu-tech.com/hubfs/img-lunascapewallet10.png" width="400" loading="lazy" />
