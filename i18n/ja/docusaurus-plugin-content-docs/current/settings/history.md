# 履歴設定

履歴の設定

![Screenshot 2025-09-11 at 16.31.31.png](img/Screenshot_2025-09-11_at_16.31.31.png)

## 新しいタブで履歴を開く

有効にすると、履歴をクリックすると、Webサイトが新しいタブで読み込まれます。

無効にすると、履歴をクリックすると、Webサイトが現在のタブで読み込まれます。

*デフォルト：有効*

## 履歴をクリア

ユーザーが履歴をクリアアクションを実行すると、確認ダイアログが表示され、同意するとすべてのブラウジング履歴が削除されます。

## Cookieを削除

ユーザーがCookieを削除アクションを実行すると、確認ダイアログが表示され、同意するとすべてのWeb Cookieが削除されます。

Web Cookieは、ユーザーがWebをブラウジングする際にサポートするコンポーネントです。
例えば、ユーザーがWebサイトAにログインすると、ブラウザによってCookieが保存されます。WebサイトAへのその後の訪問では、ユーザーはログインする必要がなく、ログイン状態でWebを使用します。このCookieがブラウザから削除されると、ユーザーはWebサイトAに再度ログインする必要があります。

## キャッシュをクリア

ユーザーがキャッシュをクリアアクションを実行すると、確認ダイアログが表示され、同意すると、Webキャッシュ全体が削除されます。

Webキャッシュは、ユーザーがWebをより高速にブラウジングするのに役立つコンポーネントです。初めてWebをブラウジングする際、Webコンポーネントが新しく読み込まれ、キャッシュされます。次のWebブラウジングでは、キャッシュされたコンポーネントを新しく読み込む必要がないため、Webがより高速に読み込まれ、より多くの帯域幅を節約します。
