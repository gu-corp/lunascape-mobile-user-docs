# 設定概要

ブラウジング体験をカスタマイズするために、Lunascapeブラウザの様々な設定を構成します。

## 目次

- [一般](general) - 基本的なブラウザ設定と設定
- [デフォルトブラウザ](default-browser) - Lunascapeをデフォルトブラウザに設定
- [表示](display) - 外観と表示設定をカスタマイズ
- [ブックマーク](bookmarks) - ブックマーク設定と設定を構成
- [検索](search) - 検索エンジンと検索設定をセットアップ
- [履歴](history) - ブラウジング履歴設定を管理
- [ウォレット](wallet) - ウォレットとWeb3設定を構成
- [プライバシー](privacy) - プライバシーとセキュリティ設定
- [サポート](support) - サポートとヘルプ情報にアクセス
- [デフォルトにリセット](reset-to-default) - すべての設定をデフォルト値にリセット

## このセクションでカバーする内容

このセクションでは、Lunascapeブラウザ設定の構成とカスタマイズ方法を説明します。以下の方法を学びます：

- 一般的なブラウザ設定とデフォルトブラウザ設定のセットアップ
- ブラウザの表示と外観のカスタマイズ
- ブックマーク、検索、履歴設定の構成
- ウォレットとWeb3機能のセットアップ
- プライバシーとセキュリティ設定の管理
- 必要に応じてサポートにアクセスし、設定をリセット

これらの設定により、ブラウジング習慣と設定に合わせてLunascapeをパーソナライズできます。
