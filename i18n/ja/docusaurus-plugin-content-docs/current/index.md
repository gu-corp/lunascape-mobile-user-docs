# はじめに

import { Button } from '@site/src/components/ui/button';

**Lunascapeモバイルブラウザ**のユーザーガイドへようこそ。このガイドは、モバイルデバイスでLunascapeブラウザを使用する際の基本的な操作方法から高度な機能まで、包括的にサポートすることを目的としています。

Lunascapeは、高速で安全なモバイルブラウジング体験を提供することを目指しています。直感的なユーザーインターフェースと豊富な機能により、いつでもどこでも快適にウェブブラウジングを楽しむことができます。

このガイドでは以下の内容について説明します：

- 基本的なブラウジング機能（タブ操作、ブックマーク、履歴など）
- 便利な機能（検索、翻訳、画像保存など）
- よくある質問とトラブルシューティング
- サポート情報

Lunascapeモバイルブラウザの機能を最大限に活用し、快適なブラウジング体験をお楽しみください。


**Lunascapeモバイルブラウザ**の使用方法について、以下のガイドをご参照ください
