title: ウェブ検索
---


次の手順で、ウェブ検索を行うことができます。

1. 左下に表示されている虫眼鏡のアイコンか、上にあるサーチバーをタップします。

<img alt="img-websearch-1" class="hs-image-align-none" height="757" src="https://www.gu-tech.com/hubfs/img-websearch-1.png" width="350" loading="lazy" />

2. 検索バー上部に表示されるお好きな検索媒体タブをスワイプして探し、

　タップで選択してください。

<img alt="img-websearch2" class="hs-image-align-none" height="757" src="https://www.gu-tech.com/hubfs/img-websearch2.png" width="350" loading="lazy" />

3. 検索バーにウェブ検索したい単語を入力し「検索」をタップします。

<img alt="img-websearch3" class="hs-image-align-none" height="757" src="https://www.gu-tech.com/hubfs/img-websearch3.png" width="350" loading="lazy" />
