# Introduction

import { Button } from '@site/src/components/ui/button';

Welcome to the **Lunascape Mobile Browser** user guide. This guide is designed to comprehensively support you from basic operations to advanced features when using the Lunascape browser on mobile devices.

Lunascape aims to provide a fast and secure mobile browsing experience. With an intuitive user interface and rich features, you can enjoy comfortable web browsing anytime, anywhere.

This guide covers the following topics:

- Basic browsing functions (tab operations, bookmarks, history, etc.)
- Useful features (search, translation, image saving, etc.)
- Frequently asked questions and troubleshooting
- Support information

Make the most of Lunascape Mobile Browser's features and enjoy a comfortable browsing experience.

Please refer to the following guides for how to use the **Lunascape Mobile Browser**
