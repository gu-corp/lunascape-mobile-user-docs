# はじめに

Lunascape Mobileは、日常的なWebブラウジングに広告ブロック、RSSニュースリーダー、Web3ウォレットを統合したモバイルブラウザです。

## Lunascape Mobileをダウンロード

- [iOS版をダウンロード](https://itunes.apple.com/app/ilunascape/id380065805?mt=8)
- [Android版をダウンロード](https://play.google.com/store/apps/details?id=jp.co.lunascape.android.ilunascape)

## 主な機能

- Webサイトと動画の広告をブロックします。
- EVM互換のWeb3ウォレットを内蔵しています。
- RSSニュースフィードをブラウザ内でまとめて閲覧できます。
- プライベートブラウジングとプライバシー設定を提供します。
- ショートカット、ブックマーク、履歴、ダウンロード、タブを管理できます。

## 問題が起きた場合

1. Webページを再読み込みするか、問題が起きている画面を閉じて開き直します。
2. 端末のネットワーク接続を確認し、同じサイトが別のタブで開くか確認します。
3. Webページの表示が崩れる場合は、[広告ブロック](../../browser/i18n/ja/ad-blocking.md)または[Webサイトのナイトモード](../../settings/i18n/ja/display.md#webサイトのナイトモード)を一時的に無効にして再読み込みします。
4. Lunascapeを再起動し、利用できる最新のアプリとOSの更新を適用します。
5. 改善しない場合は、[ヘルプとアプリ情報](../../settings/i18n/ja/support.md)を確認してください。問い合わせには、アプリのバージョン、端末名、OSのバージョン、再現手順を記載します。パスワード、リカバリーフレーズ、秘密鍵は記載しないでください。

Cookieの削除や設定のリセットを行うと、Webサイトからログアウトしたり、カスタマイズが失われたりします。実行前に[履歴とWebサイトデータ](../../settings/i18n/ja/history.md)または[デフォルトにリセット](../../settings/i18n/ja/reset-to-default.md)を確認してください。
