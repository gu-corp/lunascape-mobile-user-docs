# ウォレット設定

**設定** > **ウォレット**では、ブラウザウォレット機能の表示を切り替えたり、詳細設定を開いたりできます。

<img src="img/Screenshot_2025-09-11_at_16.52.12.png" alt="ウォレット設定の画面" width="560" />

## ウォレット設定

**ウォレット設定**をタップすると、ウォレット固有の設定を変更できます。

## ブラウザウォレットを有効にする

有効にすると、ブラウザウォレットへの入口がアプリに表示されます。無効にすると入口が非表示になり、再び有効にするまでウォレット機能を利用できません。

**初期値:** 有効

> **注意:** この設定を無効にしても、作成済みのウォレットは削除されません。リカバリーフレーズや秘密鍵は誰にも共有しないでください。
