# 設定の概要

ホーム画面から**設定**を開くと、Lunascapeの表示や動作を変更できます。

## 目的から設定を探す

| 変更したい内容 | 設定項目 |
| --- | --- |
| タブ、ショートカット、広告ブロック、ニュース、ホームウィジェット | [一般](general.md) |
| アプリのテーマ、Webサイトの表示、ツールバー、言語 | [表示](display.md) |
| ほかのアプリのリンクを開くブラウザ | [デフォルトブラウザ](default-browser.md) |
| ブックマークの取り込みや開き方 | [ブックマーク](bookmarks.md) |
| 検索方法や検索サービス | [検索](search.md) |
| 履歴、Cookie、キャッシュ | [履歴](history.md) |
| ブラウザウォレットの表示や詳細設定 | [ウォレット](wallet.md) |
| アプリのロックや閲覧データの自動削除 | [プライバシー](privacy.md) |
| バージョン情報、リリースノート、ヘルプ | [サポート](support.md) |

複数の設定を元に戻したい場合は、[デフォルトにリセット](reset-to-default.md)を参照してください。

> **ヒント:** このマニュアルでは、アプリに表示される名称を太字で示します。端末やアプリのバージョンによって、利用できる項目が一部異なる場合があります。
