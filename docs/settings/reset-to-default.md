# Reset to Default

Use this option when you want to undo your customizations or when a settings-related issue continues after restarting the app.

## Reset the settings

1. Open **Settings**.
2. Tap **Reset to Default**.
3. Review the confirmation message.
4. Confirm the reset.

After the reset, switches, display preferences, tab behavior, and other app settings return to their initial values.

> **Important:** You cannot undo a reset. Review the confirmation screen to see exactly which data your app version will change. Back up anything important before continuing.
