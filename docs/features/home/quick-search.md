# Quick Search

Use Quick Search to search with the selected search engine or open information from a QR code.

## Search from the Home screen

1. Tap the Quick Search field.
2. Enter a keyword or web address.
3. Select a suggestion or submit the search.

The result opens using the search engine selected in **Settings** > **Search**.

## Scan a QR code

1. Tap the QR code icon in Quick Search.
2. Allow camera access if prompted.
3. Point the camera at the QR code.
4. Review the detected content before opening it.

Quick Search recognizes plain text, web addresses, deep links, and WalletConnect links.

> **Security tip:** Check the destination before opening a QR code or approving a WalletConnect request.
