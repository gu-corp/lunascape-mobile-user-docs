# クイック検索

クイック検索では、選択中の検索エンジンによる検索と、QRコードからの情報読み取りができます。

## ホーム画面から検索する

1. クイック検索欄をタップします。
2. キーワードまたはWebアドレスを入力します。
3. 候補を選ぶか、検索を実行します。

検索結果は、**設定** > **検索**で選択した検索エンジンを使用して開きます。

## QRコードを読み取る

1. クイック検索のQRコードアイコンをタップします。
2. 求められた場合はカメラへのアクセスを許可します。
3. カメラをQRコードへ向けます。
4. 読み取った内容を確認してから開きます。

プレーンテキスト、Webアドレス、ディープリンク、WalletConnectリンクを読み取れます。

> **セキュリティ上の注意:** QRコードやWalletConnectリクエストを開く前に、接続先を確認してください。
