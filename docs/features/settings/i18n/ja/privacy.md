# プライバシー設定

**設定** > **プライバシー**では、アプリへのアクセスを保護したり、閲覧データを自動削除したりできます。

<img src="img/Screenshot_2025-09-11_at_17.08.09.png" alt="プライバシー設定の画面" width="560" />

## スクリーンロックを有効にする（iOSのみ）

有効にすると、Lunascapeを開く際にFace ID、Touch ID、または端末のパスコードによる認証が必要になります。

**初期値:** 無効

> **注意:** スクリーンロックは、第三者がアプリを簡単に開くことを防ぐ機能です。Web通信を暗号化したり、端末自体のセキュリティ設定を置き換えたりするものではありません。

## 閉じるときにプライバシーデータを削除

有効にすると、アプリを閉じるたびに、閲覧履歴、検索履歴、WebサイトのCookie、キャッシュが削除されます。

**初期値:** 無効

> **重要:** Webサイトからログアウトする場合があり、削除されたデータは復元できません。ブックマークとダウンロード済みファイルは、削除対象として記載されていません。
