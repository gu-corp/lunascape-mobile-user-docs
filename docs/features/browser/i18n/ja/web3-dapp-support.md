# Web3 DAppサポート

対応するWeb3 DAppへウォレットを接続し、アカウントの確認やトランザクションの承認ができます。

## 接続する前に

- 接続先のURLが正しいことを確認します。
- DAppが要求するネットワークと、ウォレット側のネットワークが一致していることを確認します。
- 接続や署名の要求内容が不明な場合は承認しないでください。

## DAppへ接続する

1. 接続するDAppをブラウザで開きます。
2. DApp側の**Connect Wallet**または同等のボタンをタップします。
3. 使用するウォレット接続方式を選びます。
4. 表示された接続先と権限を確認して承認します。

<img src="img/Simulator_Screenshot_-_iPhone_15_-_2025-09-10_at_11.00.50.png" alt="Web3 DAppサポートの画面" width="360" />

WalletConnect、MetaMask、Coinbase Walletなど、DApp側が提示する対応方式を利用できます。

> **重要:** シークレットリカバリーフレーズや秘密鍵は、Webサイトや第三者へ入力・送信しないでください。署名や送金は取り消せない場合があります。内容と送信先を必ず確認してください。
