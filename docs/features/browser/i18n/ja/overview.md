# ブラウザの概要

Lunascapeのブラウザでは、通常のWeb閲覧に加えて、広告ブロック、ファイルのダウンロード、プライベートブラウジング、Web3 DAppへの接続ができます。

## よく使う操作

| 操作 | ヘルプ |
| --- | --- |
| Webを検索する | [検索](search.md) |
| ページを保存する | [ブックマーク](bookmarks.md) / [リーディングリスト](reading-list.md) |
| 開いているページを整理する | [タブ操作](tab-operations.md) |
| 過去に開いたページを探す | [ブラウジング履歴](browsing-history.md) |
| ページやファイルを保存・共有する | [ファイルダウンロード](download-file.md) / [共有](share.md) |
| ページ上の便利な機能を使う | [ブラウザツールメニュー](browser-tool-menu.md) |

## プライバシーとWeb3

- 広告を減らしたい場合は、[広告ブロック](ad-blocking.md)を有効にします。
- 閲覧データを端末に残したくない場合は、[プライベートモード](private-mode.md)を使用します（iOSのみ）。
- DAppに接続する場合は、[Web3 DAppサポート](web3-dapp-support.md)の注意事項を確認してください。

> **ヒント:** 画面下部のツールメニューには、表示中のページで使える操作がまとめられています。
