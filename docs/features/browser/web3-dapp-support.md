# Web3 DApp Support

Lunascape can connect supported Web3 DApps to the built-in wallet. A DApp may request permission to view an account, switch networks, add a token, sign a message, or submit a transaction.

## Before connecting

- Confirm that you trust the DApp and its web address.
- Check the selected wallet account and network.
- Read every permission, signature, and transaction request before approving it.

## Connect a DApp

1. Open the DApp in Lunascape.
2. Select the DApp's wallet connection action.
3. Choose Lunascape when available, or use WalletConnect.
4. Review the connection request and approve it only if the details are correct.

<img src="img/Simulator_Screenshot_-_iPhone_15_-_2025-09-10_at_11.00.50.png" alt="Web3 DApp Support screen" width="360" />

Some DApps list compatible connection methods by another wallet or provider name. See [Wallet Operations](../wallet/wallet-operations.md) and [WalletConnect](../wallet/walletconnect.md) for detailed procedures.

> **Important:** Connecting a wallet does not require sharing a seed phrase or private key. If a website asks for either one, stop and leave the site.
