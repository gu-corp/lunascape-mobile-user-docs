# News Settings

Manage the RSS feeds shown on the News screen.

## Add or edit a feed

1. Open **Settings** > **General** > **News**.
2. Add a feed, or select an existing feed to edit it.
3. Enter the feed name and RSS URL.
4. Save the changes.

You can also delete feeds and change their display order.

<img src="img/IMG_3420_2.png" alt="News Settings screen 1" width="360" />

## Restore the default feeds

1. Open the News settings screen.
2. Select **Reset Feeds**.
3. Confirm the reset.

The current list is replaced with the defaults selected for the app language and device region. See [Default RSS Sources](default-rss-sources.md).

<img src="img/IMG_3421_2.png" alt="News Settings screen 2" width="360" />

> **Note:** Resetting removes custom changes to the feed list.
