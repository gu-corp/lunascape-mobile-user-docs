# ニュースソース選択

アプリの更新によってデフォルトのニュースソースが変わった場合、保存済みリストとの違いを確認する画面が表示されます。

## ニュースソースを確認する

1. 表示されたニュースソースを確認します。
2. 引き続き使用するソースを選択します。
3. **新規**と表示されたソースを確認します。これは新しい初期リストに追加されたソースです。
4. 選択内容を確定します。

選択しなかったソースは現在のフィードリストへ追加されません。リストは後からニュース設定で変更できます。
