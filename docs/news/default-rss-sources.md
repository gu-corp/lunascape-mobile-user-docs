- **Language-Only Fallback**: If no specific region match is found, it falls back to just the language code (e.g., `en`, `es`, `fr`)
- **Default Fallback**: If neither match is found, it returns the default English BBC News sources

The application supports the following specific combinations:

**English Variants:**

- en-us → New York Times (USA)
- en-ca → Global News (Canada)
- en-au → ABC News (Australia)
- en (default) → BBC News (UK)

**Spanish Variants:**

- es-mx → El Siglo de Torreón (Mexico)
- es-ar → Clarín (Argentina)
- es (default) → El País (Spain)

**Other Languages:**

- ja → Infoseek (Japanese)
- vi → VnExpress (Vietnamese)
- zh-cn → General Chinese news sources
- ar → Al Masry Al Youm (Arabic)
- pt → RTP (Portuguese)
- ru → MK.ru (Russian)
- fr → Le Monde (French)
- de → Der Spiegel (German)
- hi → News18 (Hindi)
- bn → Hindustan Times (Bengali)
- id → AntaraNews (Indonesian)
- tr → Hürriyet (Turkish)
- it → ANSA (Italian)
- ko → YNA (Korean)
- th → Prachachat (Thai)
- nl → Telegraaf (Dutch)
- pl → PolsatNews (Polish)
- uk → LB.ua (Ukrainian)
