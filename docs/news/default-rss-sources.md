# Default RSS Sources

Lunascape selects the initial RSS feed list using the app language and, where applicable, the device region. Changing either setting can change the list restored by **Reset Feeds**.

## Change the app language

1. Open Lunascape **Settings**.
2. Open **Display** > **Language**.
3. Select a language.

<img src="img/IMG_3424.png" alt="Lunascape language setting" width="360" />

## Change the region on iOS

1. Open the iOS **Settings** app.
2. Open **General** > **Language & Region**.
3. Select **Region** and choose the appropriate region.

<img src="img/IMG_3426.png" alt="iOS region setting" width="360" />

To apply the corresponding default list, return to Lunascape and use **Reset Feeds** in [News Settings](news-setting.md).

> **Note:** Resetting feeds replaces custom additions, deletions, and ordering.
