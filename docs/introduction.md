# Lunascape Mobile User Guide

Lunascape Mobile is a mobile browser that combines everyday web browsing with ad blocking, an RSS news reader, and a built-in Web3 wallet.

## Main features

- Blocks website and video advertisements.
- Includes an EVM-compatible Web3 wallet.
- Collects RSS news feeds in the browser.
- Provides private browsing and privacy controls.
- Supports browser shortcuts, bookmarks, history, downloads, and tab management.
