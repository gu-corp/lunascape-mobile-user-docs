# Bookmarks

Bookmarks save websites for later use. You can organize them into folders or add frequently used pages to Home screen shortcuts.

## Add the current page

1. Open the page you want to save.
2. Open the Browser Tool Menu.
3. Select **Add to Bookmark**.
4. Edit the name or destination folder if needed, then save.

<img src="img/Simulator_Screenshot_-_iPhone_15_-_2025-09-09_at_16.48.45.png" alt="Bookmarks screen" width="360" />

## Manage bookmarks

Open **Bookmarks** from the Home screen or Tool Menu. From the bookmark list you can:

- open a bookmark;
- add or rename a bookmark or folder;
- move items and change their order;
- delete an item;
- add a bookmark to Home screen shortcuts.
