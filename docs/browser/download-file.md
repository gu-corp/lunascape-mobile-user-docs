# File Downloads

Lunascape can download many common audio, video, image, document, and archive formats when a website provides a downloadable file.

## Download a file

1. Tap a download link on a web page.
2. Confirm the download if prompted.
3. Open **Downloads** from the Home screen Tool Menu to check progress or open the file.

While a download is in progress, you can pause, resume, or cancel it. Completed files can be opened, renamed, or deleted from the download list where supported.

## File locations

| Platform | Location | After uninstalling Lunascape |
| --- | --- | --- |
| iOS | **Files** > **On My iPhone** > **Lunascape** > **Downloads** | Files in the Lunascape app container are deleted. Move important files elsewhere first. |
| Android | **Downloads/Lunascape** | Downloaded files normally remain available to file manager apps. |

> **Note:** A website may prevent downloading or may stream media instead of providing a file. Storage permissions and available space can also affect downloads.
