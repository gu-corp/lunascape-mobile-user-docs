# リーディングリスト

あとで読みたいWebページをリーディングリストに保存できます。項目は**未読**と**既読**に分けて管理されます。

## ページを追加する

1. あとで読みたいWebページを開きます。
2. ブラウザのツールメニューを開きます。
3. **リーディングリストに追加**をタップします。

## 保存したページを読む

1. ブラウザのツールメニューから**リーディングリスト**を開きます。
2. 読みたい項目をタップします。

<img src="img/Simulator_Screenshot_-_iPhone_15_-_2025-09-09_at_16.55.19.png" alt="リーディングリストの画面" width="360" />

## リストを管理する

読み終えた項目は既読になり、不要な項目は削除できます。

> **注意:** リーディングリストはページの場所を保存する機能です。ページが変更・削除された場合や、オフラインの場合は表示できないことがあります。
