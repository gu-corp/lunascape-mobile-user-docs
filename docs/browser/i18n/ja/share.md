# 共有

表示中のWebページを他のアプリへ共有したり、端末に保存したりできます。

## Webページを共有する

1. 共有したいWebページを開きます。
2. ブラウザのツールメニューを開きます。
3. **共有**をタップします。
4. 共有先または実行する操作を選びます。

<img src="img/Simulator_Screenshot_-_iPhone_15_-_2025-09-10_at_10.54.16.png" alt="共有の画面 1" width="360" />
<img src="img/Simulator_Screenshot_-_iPhone_15_-_2025-09-10_at_10.54.24.png" alt="共有の画面 2" width="360" />

共有画面では、端末とWebページが対応している場合に次の操作を選べます。

- メッセージアプリやSNSなどへの共有
- 写真またはファイルへの保存
- 印刷

> **ヒント:** ファイルそのものを保存したい場合は、[ファイルダウンロード](download-file.md)も参照してください。
