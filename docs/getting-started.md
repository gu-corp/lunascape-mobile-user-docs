# Getting Started

Lunascape Mobile is a mobile browser that combines everyday web browsing with ad blocking, an RSS news reader, and a built-in Web3 wallet.

## Download Lunascape Mobile

- [Download for iOS](https://itunes.apple.com/app/ilunascape/id380065805?mt=8)
- [Download for Android](https://play.google.com/store/apps/details?id=jp.co.lunascape.android.ilunascape)

## Main features

- Blocks website and video advertisements.
- Includes an EVM-compatible Web3 wallet.
- Collects RSS news feeds in the browser.
- Provides private browsing and privacy controls.
- Supports browser shortcuts, bookmarks, history, downloads, and tab management.

## If something is not working

1. Reload the page or close and reopen the affected screen.
2. Check the device's network connection and confirm that the same site works in another tab.
3. If a page is broken, temporarily turn off [Ad Blocking](browser/ad-blocking.md) or [Website Night Mode](settings/display.md#website-night-mode), then reload it.
4. Restart Lunascape and install the latest available app and operating-system updates.
5. If the issue continues, check [Help and app information](settings/support.md). Include the app version, device model, operating-system version, and steps to reproduce the issue. Never include a password, recovery phrase, or private key.

Clearing cookies or resetting settings can sign you out or remove customizations. Read [History and website data](settings/history.md) or [Reset to Default](settings/reset-to-default.md) before using those options.
