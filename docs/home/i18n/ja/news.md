# ニュース

ニュースウィジェットには、Lunascapeに設定したRSSフィードの新着記事が表示されます。記事を直接開いたり、ニュース画面へ移動したりできます。

## 記事を読む

1. ホーム画面でニュースウィジェットを探します。
2. 記事またはニュースソースを切り替えます。
3. 読みたい記事をタップしてブラウザで開きます。

<img src="img/Simulator_Screenshot_-_iPhone_14_Pro_-_2025-10-01_at_17.25.28%201.png" alt="ニュースの画面" width="560" />

記事が表示されない場合は、RSSフィードが1件以上有効になっていることを確認し、ニュース画面を更新してください。
