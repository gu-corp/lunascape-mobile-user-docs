# Tool Menu

Provides shortcuts for quick access to features such as Bookmarks, History, Wallet, Downloads, Private Browser (iOS only), Browser Settings.

![Screenshot 2025-09-08 at 14.46.55.png](img/Screenshot_2025-09-08_at_14.46.55.png)

You can customize the position and shortcuts that are displayed.
