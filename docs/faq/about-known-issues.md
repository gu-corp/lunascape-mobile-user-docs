You can access our list of known issues at the User Forum. If you search for appropriate keywords in the forum, you might find that your problem is already registered.

The Lunascape User Forum: http://forum.lunascape.tv

If you cannot find a known issue that corresponds to your problem, we would be grateful if you would register your issue as a new topic in the User Forum, with as many details as possible, to facilitate the process of solving it.
