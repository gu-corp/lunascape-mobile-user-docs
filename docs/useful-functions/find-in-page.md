Page contents can be searched in the following way.

1. Tap the "Menu" button at the bottom of the screen

<img class="hs-image-align-none" height="709" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-24%207-40-51-png.png" width="350" loading="lazy" />

2. Tap "Find In Page"

<img class="hs-image-align-none" height="709" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-24%207-41-02-png.png" width="350" loading="lazy" />

3. Type the string you wish to search for and tap "Search"

<img class="hs-image-align-none" height="702" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-24%207-41-46-png.png" width="350" loading="lazy" />

4. The search results and number of hits will be displayed, and the search string will be highlighted in yellow where it appears in the page

<img class="hs-image-align-none" height="757" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-24%207-41-57-png.png" width="350" loading="lazy" />
