Search results can be set to always open in a new tab, as follows.

1. Tap the menu button at the bottom of the page

<img class="hs-image-align-none" height="689" src="https://www.gu-tech.com/hubfs/Top_EN-png-1.png" width="350" loading="lazy" />

2. Tap “Settings”

<img class="hs-image-align-none" height="703" src="https://www.gu-tech.com/hubfs/Setting_EN-png-1.png" width="350" loading="lazy" />

3. Tap “Tab Setting”

<img class="hs-image-align-none" height="781" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-24%206-55-17-png.png" width="350" loading="lazy" />

4. Turn on "Open New Tab from AddressBar"

<img class="hs-image-align-none" height="709" src="https://www.gu-tech.com/hubfs/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202024-01-24%206-53-47-png.png" width="350" loading="lazy" />
