# If something is not working

1. Reload the page or close and reopen the affected screen.
2. Check the device's network connection and confirm that the same site works in another tab.
3. If a page is broken, temporarily turn off [Ad Blocking](../features/browser/ad-blocking.md) or [Website Night Mode](../features/settings/display.md#website-night-mode), then reload it.
4. Restart Lunascape and install the latest available app and operating-system updates.
5. If the issue continues, check [Help and app information](../features/settings/support.md). Include the app version, device model, operating-system version, and steps to reproduce the issue. Never include a password, recovery phrase, or private key.

Clearing cookies or resetting settings can sign you out or remove customizations. Read [History and website data](../features/settings/history.md) or [Reset to Default](../features/settings/reset-to-default.md) before using those options.
